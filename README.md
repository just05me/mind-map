# Доска схем

Локальное веб-приложение для схем архитектуры и статусов задач. На одной карте можно собрать модули, сервисы, API, агентов и заметки, связать их стрелками и переключиться на доску по статусам.

Проекты хранятся в браузере (`localStorage`). Отдельный бэкенд не нужен.

## Возможности

- **Карта** — холст на [XYFlow](https://reactflow.dev/): узлы, связи, рамки, текст, стикеры, комментарии, решения
- **Доска** — те же узлы по статусам: задумано, в работе, готово, сломано
- **Типы узлов** — входы, модули, сервисы, хранилища, API, агенты, очереди, вебхуки и свои типы
- **Несколько проектов** — создание, дублирование, удаление, переключение
- **Экспорт и импорт** — JSON, Markdown и PNG карты
- **Автораскладка** — горизонтально, вертикально или вписать в экран
- **Темы** — светлая и тёмная

## Стек

- React 19 + TypeScript
- Vite 7
- [@xyflow/react](https://reactflow.dev/)
- Tailwind CSS 4
- Motion

## Запуск

Нужны [Node.js](https://nodejs.org/) 20+ и npm.

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173/**

Сервер слушает и IPv4 (`127.0.0.1`), и IPv6 (`::1`), поэтому адрес открывается в Chrome и в Safari. Если Safari сам подставляет `https://`, введите URL вручную с `http://`. Запасной адрес: http://127.0.0.1:5173/

Сборка:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Слева выберите тип узла и добавьте его на карту.
2. Соедините узлы инструментом связи или перетаскиванием от края узла.
3. Справа отредактируйте название, описание, статус и цвет.
4. Переключатель **Карта / Доска** в шапке меняет вид, узлы общие.
5. Меню **Проекты** создаёт новую схему или импортирует JSON.
6. **Экспорт** сохраняет схему в JSON, Markdown или PNG.

Данные не уходят на сервер: очистка хранилища сайта в браузере удалит проекты.
