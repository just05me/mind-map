# Доска схем

Локальное веб-приложение для схем архитектуры и статусов задач. На одной карте можно собрать модули, сервисы, API, агентов и заметки, связать их стрелками и переключиться на доску по статусам.

Проекты хранятся в браузере (`localStorage`). Отдельный бэкенд не нужен.

## Возможности

- **Схема** — холст на [XYFlow](https://reactflow.dev/) в духе FigJam: узлы, стикеры, текст, рамки, комментарии, решения, подписанные связи
- **Статусы** — те же элементы по колонкам: задумано, в работе, готово, сломано
- **Типы узлов** — входы, модули, сервисы, хранилища, API, агенты, очереди, вебхуки и свои типы
- **Правка как в Figma** — отмена и повтор, копирование, дублирование, контекстное меню, панель действий над выделением
- **Скрываемые панели** — «Элементы» слева и «Свойства» справа
- **Несколько проектов** — создание, дублирование, удаление, переключение
- **Экспорт и импорт** — JSON, Markdown и PNG схемы
- **Автораскладка** — слева направо, сверху вниз или показать всё
- **Темы** — светлая и тёмная

## Стек

- React 19 + TypeScript
- Vite 7
- [@xyflow/react](https://reactflow.dev/)
- Tailwind CSS 4
- Motion

## Запуск

Нужны [Node.js](https://nodejs.org/) 20+ и npm.

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173/**

Сервер слушает и IPv4 (`127.0.0.1`), и IPv6 (`::1`), поэтому адрес открывается в Chrome и в Safari. Если Safari сам подставляет `https://`, введите URL вручную с `http://`. Запасной адрес: http://127.0.0.1:5173/

Сборка:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Добавьте элемент: инструмент на нижней панели, тип из панели «Элементы» (клик или перетаскивание) или правая кнопка по холсту. Двойной клик по пустому холсту создаёт текст.
2. Соедините узлы: наведите на узел и потяните от точки на краю к другому узлу. Если отпустить на пустом месте, появится новый связанный узел.
3. Выделенный элемент можно перекрасить, дублировать или удалить с панели над ним, клавишей Delete или через правую кнопку. Ошиблись — ⌘Z.
4. Перетащите узел в рамку, чтобы сгруппировать; вытащите за её край, чтобы вынуть.
5. Панели скрываются кнопкой в их заголовке, клавишами `[` и `]` или ⌘\ для обеих.
6. Переключатель **Схема / Статусы** в шапке меняет вид, элементы общие.
7. Все горячие клавиши — по `?` или значку клавиатуры в шапке.

Данные не уходят на сервер: очистка хранилища сайта в браузере удалит проекты.

## Структура `src`

| Папка | Содержимое |
| --- | --- |
| `model` | Типы, каталог узлов, статусы, цвета, бумага холста |
| `canvas` | Схема: холст, узлы, связи, меню, подсказки |
| `board` | Вид по статусам |
| `ui` | Шапка, панели, меню, иконки |
| `store` | Состояние проектов и история правок |
| `export` | JSON, Markdown, PNG и скачивание |
| `lib` | Общие мелочи: id и анимация |
